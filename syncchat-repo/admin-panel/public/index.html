Match Settings

Sets the default matching scope for the country/nearby picker on the chat top bar — applies to first-time visitors before they've picked anything themselves. Existing users who've already made a choice keep their own preference.

Default scope

Works the same way for every option: if nobody's currently online in scope, the search automatically widens (e.g. Nearby falls back to same-country, then anyone) rather than waiting forever.
